# Projeto-manfredo
# Sobre o projeto
O Projeto Manfredo é um mini-projeto desenvolvido com o objetivo de aplicar

conceitos de desenvolvimento de sistemas, banco de dados e DevOps.

A aplicação utiliza tecnologias web no desenvolvimento da interface e

um banco de dados relacional para armazenamento das informações.

##  tecnologias utilizadas

- HTML

- CSS

- JavaScript

- MariaDB

- DBeaver

##  Arquitetura de Nuvem

Para o projeto, recomenda-se a utilização de uma **nuvem pública**,

utilizando o modelo de serviço **PaaS (Platform as a Service)**.

A escolha da nuvem pública permite que a aplicação seja disponibilizada

pela internet sem a necessidade de manter uma infraestrutura física própria.

O modelo PaaS é adequado porque fornece uma plataforma preparada para

hospedagem e execução da aplicação, reduzindo a necessidade de administrar

diretamente servidores, sistema operacional e outros componentes da

infraestrutura.

### Estrutura proposta

A arquitetura pode ser organizada da seguinte maneira:

**Usuário → Internet → Aplicação Web → Banco de Dados MariaDB**

A aplicação web é responsável pelo funcionamento do sistema, enquanto o

MariaDB realiza o armazenamento dos dados.

O DBeaver pode ser utilizado pelos desenvolvedores/administradores para

gerenciar e consultar o banco de dados durante o desenvolvimento.

##  Aplicação do ciclo DevOps

O ciclo DevOps foi utilizado para organizar o desenvolvimento e facilitar

a integração entre as etapas do projeto.

As principais etapas consideradas foram:

1. **Planejamento (Plan)**  

   Definição dos requisitos e das funcionalidades do sistema.

2. **Desenvolvimento (Code)**  

   Criação da aplicação utilizando HTML, CSS e JavaScript.

3. **Construção (Build)**  

   Organização dos arquivos e preparação da aplicação para execução.

4. **Testes (Test)**  

   Verificação do funcionamento das funcionalidades e da comunicação

   com o banco de dados.

5. **Lançamento (Release)**  

   Preparação da versão da aplicação para disponibilização.

6. **Implantação (Deploy)**  

   Disponibilização da aplicação no ambiente escolhido.

7. **Operação (Operate)**  

   Acompanhamento do funcionamento da aplicação e do banco de dados.

8. **Monitoramento (Monitor)**  

   Observação do desempenho e identificação de possíveis problemas.

A utilização do ciclo DevOps permite organizar melhor o desenvolvimento,

reduzir problemas durante a implantação e facilitar a manutenção do

sistema.
